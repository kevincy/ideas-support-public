高考备考助手支持说明

如果你在使用高考备考助手时遇到问题，可以先查看本页的常见问题、权限说明和数据备份建议。

适用 App

App 名称：高考备考助手

适用平台：iPhone / iOS

主要用途：学习计划、学科任务、课程记录、试卷整理、考试成绩和高考目标跟踪。

主要功能

  • 记录每日灵感、备忘、提醒和时间线。
  • 创建学科任务，跟踪完成情况、计划用时、实际用时、准确率和详细复盘。
  • 记录课程上课情况、老师、课程详情、课程反馈、讲义和课后任务。
  • 整理试卷集和试卷，保存照片、PDF、Word 文件等附件。
  • 支持本地 OCR、试卷增强、黑白处理、去阴影和全文搜索。
  • 设置高考日期、六科目标分，记录考试成绩和题型得分明细。
  • 支持中文和英文语音输入。
  • 支持数据备份和恢复，包含记录、照片和文件。

常见问题

为什么需要相机和照片权限？

相机用于拍摄试卷、课程讲义和学习资料；照片权限用于从相册导入或保存相关图片。

为什么需要麦克风和语音识别权限？

麦克风用于语音输入和录音点评；语音识别用于把语音转换成文字，方便快速填写标题、内容、科目、日期和备注。

试卷 OCR 是否需要联网？

App 的试卷 OCR 和图片处理设计为在设备本地完成。实际效果会受到照片清晰度、光线、角度、系统版本和设备性能影响。

提醒没有出现怎么办？

  1. 确认 iOS 系统设置中已允许高考备考助手发送通知。
  2. 确认提醒时间没有设置在过去。
  3. 确认设备没有开启会拦截通知的专注模式。

如何防止数据丢失？

建议定期使用 App 内的数据备份功能导出备份文件，并把备份保存到 iCloud Drive、电脑或其他可靠位置。恢复数据前请确认备份文件来自你信任的位置。

删除后的试卷或任务还能找回吗？

支持软删除的内容会先进入回收站，可在回收站中恢复。请在清理数据前确认不再需要相关内容。

故障排查

  • 如果页面显示异常，请先升级到最新版本 App，并重启 App 再试。
  • 如果拍照或相册无法使用，请在 iOS 设置中检查相机和照片权限。
  • 如果语音输入无法启动，请检查麦克风和语音识别权限，并确认设备支持所选语音语言。
  • 如果导入 PDF 或 Word 失败，请确认文件未损坏，并尝试从“文件”App 重新选择。

联系支持

如果问题仍未解决，可以通过 GitHub Issues 提交反馈：

https://github.com/kevincy/ideas-support-public/issues

提交问题时，建议说明 iPhone 型号、iOS 版本、App 版本、发生问题的页面和复现步骤。请不要在公开 Issue 中上传包含个人隐私、学生成绩、试卷原图或联系方式的敏感信息。
