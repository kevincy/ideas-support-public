# 小贝备考助手支持站点

这是小贝备考助手 App 的公开支持、隐私政策与服务条款站点。

- 线上地址：`https://kevincy.github.io/ideas-support-public/`
- 支持页：`support.html`
- 隐私政策：`privacy.html`
- 服务与购买条款：`terms.html`
- 首页：`index.html`
- 公共样式：`style.css`

当前页面内容覆盖 2.0 版本：分科考试失分分析、多次考试失分汇总、PDF 导出、各科知识点/题型/失分原因库、iCloud 同步默认关闭、免费额度、Pro 年订阅和 Pro 永久解锁。

建议在 GitHub Pages 中启用本仓库的 `main` 分支根目录发布。
